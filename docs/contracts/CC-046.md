# CC-046 — Sheet con `side="right"` apoyado en el borde derecho

- **Issue:** #630 (label `contract-change`) · **Abre:** Lautaro073 (agy) · **Fecha:** 2026-11-06
- **Contrato afectado:** `src/ui/sheet.tsx` (`SheetContent`, prop `side`)

## Actual

En `src/ui/sheet.tsx`, `SheetContent` envuelve el contenido en
`<div className="fixed inset-0 z-50 flex items-end justify-center sm:items-center">` (antes de este CC, línea 125).
El prop `side` solo cambia alto, ancho y bordes del `DialogPrimitive.Content` (`h-full max-w-md rounded-l-xl` para
`right`), pero no la alineación horizontal del contenedor. Por eso, cuando el panel es más angosto que la pantalla
(`max-w-md`, 448 px), queda centrado en vez de apoyado a la derecha.

Consumidores con `side="right"`:
- `src/app/(admin)/admin-nav.tsx:143`: menú angosto del admin (debajo de `lg`). Entre 449 y 1023 px de ancho sale
  centrado.
- `src/features/admin/components/merchant-plan-sheet.tsx` (T-405, PR #629): panel del plan en A03, centrado en
  escritorio.

Con `side="bottom"` (por defecto) el panel ocupa el ancho completo en móvil y se centra desde `sm`, que es lo
esperado.

## Propuesto

Sin cambios en la API pública. El contenedor elige la justificación según `side`:

```tsx
<div
  data-sheet-wrapper=""
  className={cn(
    'fixed inset-0 z-50 flex items-end sm:items-center',
    side === 'right' ? 'justify-end' : 'justify-center'
  )}
>
```

- `side="right"`: `justify-end`, el panel se apoya en el borde derecho.
- `side="bottom"`: sin cambios (`justify-center`).
- `data-sheet-wrapper` es solo un gancho de prueba para encontrar el contenedor; no cambia estilos ni accesibilidad.
- No se tocan el estado, el foco, el overlay, la animación (`sheetSpring`) ni las clases del contenido.
