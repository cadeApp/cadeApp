# CC-027 — MapPicker sin pin ficticio cuando faltan coordenadas (showMarkerWhenEmpty)

- **Issue:** #378 (label `contract-change`) · **Abre:** Persona 2 (agy) · **Fecha:** 2026-10-16
- **Contrato afectado:** `src/ui/map.tsx` (`MapPickerProps`, `MapPicker`)
- **Tareas bloqueadas:** T-358
- **Depende de:** Ninguno

## Actual
En `src/ui/map.tsx`:
- `MapPickerProps` no contempla una opción para indicar si debe haber un pin visible en estado inicial cuando `value === null` o `undefined`.
- Si `value` es `null`, el mapa inicializa `activeCoords` en `fallbackCenter = defaultZoneCenter ?? AGUILARES_CENTER` y renderiza incondicionalmente un `Marker` (legacy) o `AdvancedMarker` en dicha coordenada (`src/ui/map.tsx:325` y `:335`).
- Esto provoca que en pantallas de edición de perfil (como T-358) donde el comercio no tiene ubicación previa guardada (`default_pickup_lat === null`), el mapa muestre un pin ficticio en el centro de Aguilares, induciendo a error al usuario y a los oráculos de validación que detectan un pin posicionado donde no existe dato guardado.

## Propuesto
Añadir a `MapPickerProps` la propiedad opcional:
```typescript
export interface MapPickerProps {
  value?: MapCoordinates | null;
  defaultZoneCenter?: MapCoordinates | null;
  onChange?: (coords: MapCoordinates) => void;
  // ...
  /**
   * CC-027: Si es false, cuando value sea null/undefined no se renderiza ningún pin (Marker/AdvancedMarker),
   * manteniendo la cámara centrada en defaultZoneCenter o AGUILARES_CENTER.
   * Al interactuar con el mapa (click/tap), onChange emite las coordenadas y el pin aparece de forma controlada.
   * @default true para retrocompatibilidad con consumidores existentes.
   */
  showMarkerWhenEmpty?: boolean;
}
```

En la implementación de `MapPicker`:
```typescript
const hasMarker = showMarkerWhenEmpty ? true : value != null;

const isOutside =
  hasMarker &&
  (value != null
    ? !isWithinAguilaresBounds(value)
    : defaultZoneCenter != null
      ? !isWithinAguilaresBounds(defaultZoneCenter)
      : false);

// Render condicional del marcador:
{hasMarker && (
  mapId ? (
    <AdvancedMarker ... />
  ) : (
    <Marker ... />
  )
)}
```

- **Rollback:** Reversible de inmediato retirando el prop opcional sin romper código consumidor.

## Decisiones de producto
- **Decisión Lautaro073 (PR #375 / Issue #378):** Permitir `showMarkerWhenEmpty?: boolean` con default `true`. Con `false`, si `value === null` centrar viewport en zona/Aguilares sin renderizar pin. Al seleccionar por click/tap, emitir vía `onChange` y mostrar pin real controlado. Botón «Quitar ubicación» en el form anfitrión cuando haya pin presente para devolver `value` a `null`.
