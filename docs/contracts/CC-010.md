# CC-010 — Primitivas shadcn Table, Tabs e InputOTP en src/ui

- **Issue:** #107 (label `contract-change`) · **Abre:** Lautaro073 / revisión independiente · **Fecha:** 2026-09-26
- **Contrato afectado:** `src/ui/table.tsx`, `src/ui/tabs.tsx`, `src/ui/input-otp.tsx`
- **Tareas bloqueadas:** T-122 (#25, PR #106)

## Actual

El sistema de diseño ya usa shadcn/ui mediante `components.json` (`style: default`, alias `ui: "@/ui"`), pero no tiene primitivas compartidas para tablas, tabs ni OTP de un solo campo accesible con slots visuales.

T-122 implementó equivalentes locales para A00/A01/A02, pero su ficha exige que estas primitivas entren por `contract-change` y no desde la feature.

## Propuesto

Incorporar las primitivas oficiales del registry `default` de shadcn/ui.

### Table

Exports: `Table`, `TableHeader`, `TableBody`, `TableFooter`, `TableHead`, `TableRow`, `TableCell`, `TableCaption`.

No agrega dependencia propia.

### Tabs

Exports: `Tabs`, `TabsList`, `TabsTrigger`, `TabsContent`.

Dependencia directa fijada: `@radix-ui/react-tabs@1.1.21`.

### InputOTP

Exports: `InputOTP`, `InputOTPGroup`, `InputOTPSlot`, `InputOTPSeparator`.

Dependencia directa fijada: `input-otp@1.5.0`.

El wrapper conserva un único input real, `autocomplete="one-time-code"`, pegado nativo y slots visuales. Se adapta únicamente a convenciones existentes del repo: import de `cn` desde `@/ui/cn`, formato del proyecto, compatibilidad con `noUncheckedIndexedAccess`, la regla D16 que prohíbe variantes arbitrarias y la animación `animate-pulse` ya disponible.

## Motivo

T-122 necesita A00/A01/A02 y su contrato visual vincula Table, Tabs e InputOTP al sistema compartido. Mantener copias manuales dentro de `src/features/admin` fragmentaría el design system.

Lautaro073 eligió explícitamente **2-A** en la revisión de PR #106: usar las primitivas oficiales de shadcn mediante un CC separado.

## Impacto

- ¿Toca alguna decisión D1–D14 del master plan o algo que ve el usuario? **No cambia D1–D14.** Habilita la implementación visual ya aprobada de A00/A01/A02. Lautaro073 aprobó 2-A.
