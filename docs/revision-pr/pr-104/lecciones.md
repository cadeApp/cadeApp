# Lecciones — PR #104 / CC-009

## AG-102 · Un contract-change de UI no termina en la propuesta

Si la tarea bloqueada necesita una primitiva o token que no existe, el CC solo desbloquea cuando el mismo PR agrega dependencia, implementación, exports y tests.

## AG-103 · Un color semántico es un par de contraste, no un hex

Definir “WhatsApp = #25D366” es incompleto. El contrato visual incluye fondo, hover y foreground, y la matriz de contraste debe matar la mutación que cambia el foreground a uno ilegible.

## AG-104 · Una decisión cerrada no vuelve a ser un “o”

Después de que Lautaro073 elige una variante contractual, el documento deja una única obligación. Otras variantes pueden ser consumidores de esa decisión, no reemplazos alternativos.
