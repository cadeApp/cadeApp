# Lecciones — PR #377

La ficha autoritativa de una tarea puede quedar desactualizada cuando una dependencia se implementa. Corregir su dependencia y la nota final evita instrucciones contradictorias. En las PR documentales, un fallo de infraestructura de `next/font` **no** se imputa automáticamente a Markdown; validar el build del SHA real sin desactivar el check. Sin número AG nuevo: no se pudo enumerar las ramas remotas.
