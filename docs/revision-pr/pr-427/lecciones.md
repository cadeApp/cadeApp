# Lecciones de la PR #427

## Patrón dominante

Un cambio técnicamente correcto puede seguir bloqueado si la tarea declarada no autoriza el archivo modificado.

## Recomendación

Antes de abrir un fix operativo, comprobar la lista de archivos permitidos de la ficha elegida. Si no alcanza, regularizar el alcance antes de modificar el workflow.
