# T-311 — Fuentes legales verificadas

Fecha de consulta: 25 de septiembre de 2026.

Este archivo documenta fuentes oficiales utilizadas para redactar la versión inicial. No afirma revisión jurídica externa.

- Ley 25.326: https://www.argentina.gob.ar/normativa/nacional/64790/actualizacion
- Decreto 1558/2001: https://www.argentina.gob.ar/normativa/nacional/70368/actualizacion
- Derechos ante AAIP: https://www.argentina.gob.ar/aaip/datospersonales/derechos
- Transferencias internacionales: https://www.argentina.gob.ar/transferencias-internacionales
- Disposición 60-E/2016: https://www.argentina.gob.ar/normativa/nacional/267922/texto

## Aceptación electrónica
- Ley 25.506: https://www.argentina.gob.ar/normativa/nacional/70749/texto
- El checkbox se trata como evidencia electrónica de aceptación versionada; no se presenta como firma digital.
