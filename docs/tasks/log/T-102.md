### 3. Fase Verde (Implementación SQL + Wrapper Server + Tipos)
- **Migración SQL (`supabase/migrations/20260923170000_rpc_accept_offer_v1.sql`):**
  - Elimina la policy redundante `offers_update_merchant` (`drop policy if exists offers_update_merchant on public.offers;`, cerrando `PR56-H21`).
  - Implementa `public.accept_offer(p_offer_id uuid)` como `SECURITY DEFINER` con `SET search_path = public, pg_temp`.
  - Adquiere locks en orden jerárquico (`public.delivery_requests FOR UPDATE` -> `public.offers FOR UPDATE` -> `public.couriers FOR SHARE`) para serializar llamadas concurrentes sobre la misma solicitud sin deadlocks.
  - Respeta la precedencia canónica de 8 pasos documentada en `src/domain/rpc-contracts.ts` (`CC-002`) y compartida con `createFakeRpcClient`:
    1. **Actor y rol:** `UNAUTHENTICATED` (`auth.uid() is null`) -> `UNAUTHORIZED_ACTOR` (`role <> 'merchant'`)
    2. **Parámetros:** `VALIDATION_ERROR` (`p_offer_id is null`)
    3. **Existencia:** `NOT_FOUND` (oferta, solicitud o repartidor inexistentes)
    4. **Titularidad del comercio:** `UNAUTHORIZED_ACTOR` (`merchant_id <> auth.uid()`)
    5. **Idempotencia y competencia:** si `status = 'matched'` y `accepted_offer_id = p_offer_id`, retorna `ok` con `idempotent = true` y el `matched_at` original; si `status = 'matched'` con otra oferta, lanza `ALREADY_MATCHED`.
    6. **Solicitud:** expiración perezosa si `status = 'published'` y `expires_at <= now()` (`REQUEST_EXPIRED`) -> si `status <> 'published'`, lanza `INVALID_STATE_TRANSITION`.
    7. **Oferta:** si `status <> 'pending'`, lanza `OFFER_NOT_PENDING`.
    8. **Repartidor:** si `status = 'suspended'`, lanza `COURIER_SUSPENDED`; si `status <> 'approved'`, lanza `COURIER_NOT_APPROVED`.
  - Ejecuta en la misma transacción: `offers.status = 'accepted'` (`decided_at = now()`), rechazo de todas las ofertas hermanas `pending` (`status = 'rejected'`, `decided_at = now()`), y transición de `delivery_requests` a `status = 'matched'`, `accepted_offer_id = p_offer_id`, `matched_at = now()` (habilitando inmediatamente `public.is_courier_assigned_to_request` para el repartidor ganador).
  - Endurece privilegios: `revoke all on function public.accept_offer(uuid) from public, anon, authenticated; grant execute on function public.accept_offer(uuid) to authenticated;`.
- **Wrapper Server-Only (`src/server/rpc/offers.ts`) y Tipos (`src/types/database.types.ts`):**
  - Se exporta `acceptOfferRpc` y se agrega `accept_offer` a `createOffersRpcServerClient` y `mapOfferRpcError` (incluyendo traducción de `23505` a `ALREADY_MATCHED` y fallback a `INTERNAL_ERROR`).
