## Objetivo

El comercio no sabe si hay repartidores conectados y puede publicar al vacío. Con esta tarea, la app del repartidor
avisa que sigue conectada mientras tiene «Disponible» prendido, y el comercio ve en su inicio y en «Nueva solicitud»
cuántos repartidores están conectados ahora (solo el número), actualizado cada minuto. No bloquea la publicación.

## Regla de pruebas
La evidencia RED tiene que fallar por el comportamiento real que falta. Está prohibido fabricar RED o GREEN:
- comentando código;
- adulterando expectations;
- agregando ramas `if (test)`;
- usando mocks que eviten el camino de producción;
- debilitando una aserción solo para que pase CI.

Una **mutación** que rompe a propósito la regla para demostrar que el test la protege es válida si es local,
temporal, restaurada y sin commit. Si hace falta evidencia de CI (pgTAP), se usa una rama y PR aislada
`review/T-415-<mutacion>` marcada **`REVIEW ONLY / NEVER MERGE`**, que se cierra sin mergear.

## Notas para quien retome

- La hora de la señal la pone la base (`now()`); el cliente nunca la manda.
- El conteo es solo agregado: nunca se exponen identidades ni horarios de cada repartidor.
