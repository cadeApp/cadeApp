# T-331 — El pipeline E2E descubre las specs por proyecto de Playwright

- **Zona / dueño:** P1 · **Issue:** #232 · **Fase:** Fase 3 (Calidad, operación y salida)
- **Dependencias (mergeadas en develop):** T-327, T-329
- **Bloquea:** —
- **Contratos a leer:** `AGENTS.md`, `e2e/AGENTS.md`, `.github/workflows/e2e-preview.yml`,
  `.github/workflows/e2e-staging.yml`, `playwright.config.ts`

## Origen

`e2e-preview.yml` y `e2e-staging.yml` tenían hardcodeada la lista de specs: `smoke`, `main-flow` y un
`if [ -f … ]` por cada spec opcional (`request-states`, `notifications`, `subscription.global-settings`).
`verify-workflows.test.mjs` exigía esa lista exacta. Como `AGENTS.md` prohíbe que una tarea toque `.github/**`, cada
tarea que agregaba un spec E2E necesitaba una PR de fix aparte para sumarlo al pipeline (T-329 fue una de ellas).
Lo pidió Lautaro073 el 2026-10-03.

## Objetivo

Que los gates corran los proyectos de `playwright.config.ts` en lugar de una lista:

- `chromium`: todo `e2e/specs/*.spec.ts` salvo `*.global-settings.spec.ts`;
- `global-settings`: solo `*.global-settings.spec.ts`, en serie.

Un spec nuevo en `e2e/specs/` entra solo al gate, sin tocar `.github/**`.

## Decisiones

- **Preview:** `pnpm exec playwright test --project=chromium --workers=1` y después
  `pnpm exec playwright test --project=global-settings --workers=1 --pass-with-no-tests`. Con `--pass-with-no-tests`,
  que el SHA no tenga ningún spec `global-settings` no es un fallo, igual que el `if [ -f … ]` anterior.
- **Staging:** solo el proyecto `chromium`, como antes. `global-settings` sigue fuera de staging porque cambia
  `platform_settings` de la base compartida (T-329 lo agregó solo a preview).
- **Seguridad:** no cambia el modelo de confianza de T-327. `e2e-preview` ya ejecutaba specs del SHA de la PR con
  los secrets de Develop: una PR interna podía modificar `main-flow.spec.ts` y correr igual. Siguen iguales la
  resolución de la PR interna, el bloqueo por migraciones, `--workers=1`, la concurrencia y los secrets limitados al
  step de Playwright.
