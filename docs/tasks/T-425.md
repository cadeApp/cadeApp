# T-425 — Admin: barra lateral contraíble a íconos con tooltip

- **Zona / dueño:** P1 · **Issue:** #634 · **Fase:** Fase 4 — pedido de Lautaro073 (2026-11-06), cambio visual
- **Dependencias (mergeadas en develop):** T-402 (shell del admin)

## Objetivo

En escritorio (≥ `lg`) la barra lateral del admin tiene un botón «Contraer menú» / «Expandir menú». Contraída mide
`w-20`: cada sección y «Salir» quedan como ícono con su nombre en un tooltip (Radix, patrón shadcn/ui) y como texto
para lectores de pantalla; el logo muestra solo la moto y el nombre del operador queda oculto a la vista. El menú
angosto (Sheet) no cambia.

## Dependencia nueva

- `@radix-ui/react-tooltip` 1.4.1 (primitiva Radix del Tooltip de shadcn/ui, regla 25), pedida por Lautaro073.
