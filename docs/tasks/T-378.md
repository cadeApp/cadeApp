# T-378 — Flecha para volver en el viaje y error de oferta en rojo

- **Zona / dueño:** P2 · **Issue:** #439 · **Fase:** Fase 3 (Calidad, operación y salida)
- **Dependencias (mergeadas en develop):** T-114, T-115, T-336
- **Contratos a leer:** `src/features/trips/components/trip-{courier,merchant}-view.tsx`,
  `src/features/offers/components/{offer-sheet,my-offers-list,courier-feed}.tsx`, `tailwind.config.ts`

## Problema verificado

QA en staging (2026-10-20):

1. La vista de viaje («Viaje en curso») no tiene una flecha para volver; el encabezado solo muestra el código, el
   título y el estado.
2. El error «La oferta es menor al monto mínimo permitido.» no se ve en rojo. `offer-sheet.tsx`, `my-offers-list.tsx`
   y `courier-feed.tsx` usan `text-danger`, `bg-danger`, `border-danger` y `ring-danger`, pero `tailwind.config.ts` no
   define el color `danger` (sí `destructive`), así que esas clases no generan estilo.

## Objetivo

Que se pueda volver desde el viaje al inicio de cada rol y que los errores de ofertas se vean en rojo con el token del
tema, marcando el monto como inválido.
