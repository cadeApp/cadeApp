## Decisiones arquitectónicas
- **D01:** Conexión de `CourierFeed` (`src/features/offers/components/courier-feed.tsx`) con el hook `useAvailableRequests` para reflejar solicitudes en vivo.
- **D02:** Eliminación del refetch no-op en `useTrip`; consulta a fuente viva de datos.
- **D03 / 1-A:** Las lecturas/refetch de datos vivos salen de los hooks de feature y pasan por endpoints server en `/api/live/*`. Supabase Realtime cliente queda exclusivamente para invalidar queries de TanStack Query.
- **D04 / 1-A:** Paginación de punta a punta (SSR + live API + hooks + UI + índices) en las dos listas de T-204 (`available-requests` y `request-offers`). Máximo 50 elementos por página con keyset cursor `created_at desc, id desc`.
